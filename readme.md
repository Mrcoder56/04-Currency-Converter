# 💱 Currency Converter App

A modern Currency Converter built using HTML, CSS, and JavaScript.

## Features
- 🌍 Convert between multiple currencies
- 💱 Real-time exchange rates using an API
- 🏳️ Dynamic country flags
- 📱 Responsive design
- ⚡ Fast and easy to use

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
- Fetch API
- Currency Exchange API
